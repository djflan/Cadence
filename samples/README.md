# Samples

| File | Description |
| ---- | ----------- |
| `cadence-demo.mid` | An original eight-bar demo (drums, bass, keys, lead; GM programs) written for Cadence. Format 1, 480 PPQN, 120 BPM, with a marker. |
| `canon-gm16.mid` | Pachelbel's Canon in D (public domain) arranged for all 16 GM channels, one track per channel, drums on 10. Format 1, 480 PPQN, about 51 seconds. An import fixture: GM System On SysEx, bank select, program changes, mixer controllers, RPN pitch-bend range, pitch bend, channel pressure, sustain, expression, lyrics, key signature, copyright text, tempo and meter changes, markers, running status, both note-off styles, and same-tick retriggers. |

`canon-gm16.mid` is generated by `canon-gm16.py` (Python 3, standard library only), which writes the
bytes directly rather than through Cadence. Run `python3 samples/canon-gm16.py` to regenerate it; the
output is deterministic. If you change the script, update the expected values in
`SampleFileTests`.

The samples are original works by Cadence contributors, released under the repository's MIT
licence, and safe to redistribute and use as test fixtures.
